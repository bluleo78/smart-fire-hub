# WD-796 — 통합 PR #1047(WD-788) 리뷰 후속 설계 (짧은 설계)

자율 work-loop 세션이라 설계 승인은 스스로 했다(이슈 본문이 고칠 방향을 적어 두었고, 사람에게 물을 UI/UX 갈림이 없다).

## 의도
AI 팀장이 머지를 막지 않은 지적 4건을 확인해 고친다. 목표는 거짓 경고·소리 없는 삭제·문구 오류·시험 간섭을 없애는 것이다. 동작을 넓게 바꾸는 것은 목표가 아니다.

## 항목별 결정
1. **토스트 조사**
   - 결정: 조사가 필요 없는 문장 「다른 곳에서 인증 방식이 바뀌어(<라벨>), 고친 인증 칸을 새 값으로 바꿨습니다.」으로 바꾼다.
   - 버린 대안: 라벨마다 받침을 판정하는 것은 라벨이 바뀔 때마다 깨질 수 있어 버렸다.
2. **다른 곳에서 더하거나 이름을 바꾼 추가 헤더**
   - 결정: `syncStoredRows` 가 새 기준에만 있는 저장 헤더(이전 기준에 없던 storedName)를 고친 덩어리 끝에 더하고, `addedNames` 로 알린다. 토스트는 「다른 곳에서 추가 헤더(Y)가 더해져 목록에 넣었습니다.」이다.
   - 이름 변경(X-Id → x-id)은 지워짐 + 더해짐으로 함께 알린다.
   - 사용자가 같은 이름(대소문자 무시)의 새 행을 이미 써 두었으면 그래도 더한다. 그러면 기존 중복 검증(`extraHeaderRowErrors`)이 저장 때 잡아 사용자가 고르게 된다 — 소리 없이 덮어쓰지 않는다.
   - 버린 대안: 「덮어쓴다고 경고만」은 저장하면 여전히 지워지므로 버렸다.
3. **재료 수 중복 셈**
   - 결정: 줄의 재료 값을 nearlyEqual 기준으로 서로 다른 값만 남긴 뒤, 그 수로 두 상한(MAX_RATE_OPERANDS 8, MAX_INTEGER_RATE_OPERANDS 4)을 본다.
   - 같은 값 쌍은 어차피 건너뛰므로 판정 결과는 그대로이고, 순서쌍만 줄어든다.
4. **Qdrant 회귀 시험**
   - 결정: 회귀 시험은 행 키워드 컬렉션 하나만 지운다(`deleteCollectionAsync(keyword)`).
   - `restoreCollectionsWipedByOtherTests` 는 `ready` 필드가 null 이면 시험을 실패시킨다(필드 이름이 바뀐 것을 조용히 넘기지 않게).
   - 다른 시험들의 전체 삭제는 컬렉션 이름이 고정이라 범위를 좁힐 수 없다 — 영향 범위만 확인해 PR 에 적는다.

## 제약
- 이 컨테이너는 메모리 16GB 를 두 세션이 나눠 쓴다. 기차 33 게이트가 도는 동안에는 gradle·Playwright 를 돌리지 않는다 — 게이트가 끝난 뒤 돌린다.
