# 데이터 현황 질문지 — 내부 해석 가이드

`customer-data-survey.md`(고객용) 답변을 받았을 때, 미팅에서 **우리 안을 어떻게 설명할지**와 **도입 전에 무엇을 확인해야 하는지**를 정리한 내부 문서입니다. 고객에게 보내지 않습니다.

제품 기능·제약은 2026-10-06 코드 기준입니다. 미팅 전에 바뀐 점이 없는지 확인합니다.

## 1. 보유 데이터 → 데이터셋 구성

| 답변 | 우리 안 | 확인할 것 |
| --- | --- | --- |
| 표 데이터(전표·고객·재고 등) | 테이블 데이터셋. 필드 정의·값 분포·이력, SQL·차트·대시보드 | 데이터 간 공통 키(거래처 코드 등) — 지식그래프·조인의 전제 |
| 문서(PDF·Word·텍스트) | 문서 데이터셋 → 자동 색인, 의미 검색, AI 질의응답, 지식그래프 추출 | 지원 형식은 PDF·DOCX·TXT·MD. **스캔 이미지 PDF·한글(HWP)은 지금 처리 못 함** |
| 파일(이미지·도면) | 파일 데이터셋(오브젝트 저장소) | 내용 분석이 아니라 보관·조회 수준임을 분명히 |
| 주소·좌표가 있는 데이터 | 지도 탭, 지도 차트 | 지도 바탕 타일은 인터넷이 필요 — 망분리면 지도 배경이 안 나옴 |
| 규모 | 서버 사양 산정 근거 | 수천만 행 이상·수만 건 문서면 별도 성능 검토 |

## 2. 현재 분석 방식 → 시연 시나리오

| 답변 | 앞세울 기능 |
| --- | --- |
| 엑셀 수작업 집계·보고가 많다 | AI 어시스턴트(말로 묻고 표·차트로 답), 정기 보고서 자동 작성, 파이프라인 일 집계 |
| BI 도구를 이미 쓴다 | BI 가 못 하는 것: 문서 검색·AI 질의응답, 글 데이터 AI 분류, 지식그래프 |
| 매일 보는 지표가 있다 | 대시보드(자동 새로고침), 스마트 작업 이상 탐지 알림 |
| 문의·민원·클레임 원문이 쌓인다 | 파이프라인 AI 분류(긴급도·유형·근거) |
| 외부 용역으로 분석한다 | 데이터를 밖에 주지 않고 내부에서 분석 — 반출 부담 감소 |

## 3. 저장·관리 → 데이터 수집 방식

| 답변 | 우리 안 | 확인할 것 |
| --- | --- | --- |
| 파일로 내보낼 수 있다 | CSV·XLSX 업로드(추가·교체·Upsert), 문서 업로드 | 주기적 갱신이면 사람이 올릴지, 자동화가 필요한지 |
| REST API 가 있다 | API 연결 + API 가져오기 마법사 / 파이프라인 API 호출 단계(스케줄) | 인증 방식은 API 키·Bearer 만 지원. 사설망 주소 API 는 SSRF 가드에 막히는지 확인 |
| **DB 직접 접속만 된다** | **지금 외부 DB 커넥터 없음** | 파일 내보내기·API 를 요청하거나, 커넥터 개발 필요 — 약속 전에 내부 협의 |
| 전담 관리 부서가 있다 | 데이터셋 인증 상태·카테고리·이력으로 관리 체계 설명 | |

## 4. 보안 규정 → AI 구성과 권한 설계

| 답변 | 우리 안 | 확인할 것 |
| --- | --- | --- |
| 부서·직급별 열람 규정 | 역할별 권한, 워크스페이스(조직) 분리, 감사 로그 | **같은 데이터 안에서 사람별 행 단위 제한**(예: 영업담당은 자기 거래처만)은 지원 여부 미확인 — 약속 금지 |
| 외부 AI **가능** | 지금 구성 그대로(외부 AI 모델 연결) | |
| 외부 AI **가명 처리 후 가능** | 가명 처리된 데이터셋으로 구성 | 자동 가명 처리 기능은 없음 — 고객 쪽 처리 또는 파이프라인으로 구현 |
| 외부 AI **불가** | 사내 AI 모델(OpenAI 호환) 연결 | **지금은 사설망 모델 서버를 연결할 수 없음**(HTTPS 443/8443 + 사설 IP 차단). 이 수정이 먼저 필요 |
| 망분리 | 전 구성요소 사내 설치 | 지도 타일·외부 API·외부 AI 모두 막힘. 임베딩은 사내 Ollama 허용 목록으로 가능 |
| 사내 AI 모델 보유 | 대화·분류 모델로 연결, 임베딩은 사내 Ollama | 모델이 도구 호출(function calling)을 지원하는지 — AI 어시스턴트 동작의 전제 |
| 사내 계정 연동(SSO·LDAP) 요구 | — | **지원 안 함**(이메일·비밀번호 로그인만) |
