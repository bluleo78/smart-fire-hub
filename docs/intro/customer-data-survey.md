# Gen:iA Data 데이터 현황 사전 질문지

귀사의 데이터 현황을 대략 파악해, 귀사 환경에 맞는 구성안을 준비하기 위한 질문지입니다.

- 15분 정도면 충분합니다. 아는 만큼만 간단히 적어 주세요.
- 모르는 항목은 비워 두셔도 됩니다. 미팅에서 함께 채우겠습니다.
- 실제 데이터 값(고객명, 금액 등)은 적지 마세요. 데이터의 이름·형태·규모만 알려 주시면 됩니다.

## 1. 어떤 데이터가 있나요

분석이나 보고에 쓰는 주요 데이터를 한 줄에 하나씩 적어 주세요. 처음 두 줄은 예시입니다.

| 데이터 | 형태 | 규모(대략) | 저장 위치 | 갱신 주기 | 담당 부서 |
| --- | --- | --- | --- | --- | --- |
| (예) 매출 전표 | 표 | 연 5만 건 | ERP(사내 DB) | 매일 | 재무팀 |
| (예) 거래 계약서 | 문서(PDF) | 2천 건, 5GB | 파일 서버 | 수시 | 영업관리팀 |
| | | | | | |
| | | | | | |
| | | | | | |
| | | | | | |

- **형태:** 표(행·열로 된 데이터), 문서(PDF·Word·한글·스캔본 등), 파일(이미지·도면 등)
- **규모:** 표는 건수(행 수), 문서·파일은 건수와 전체 용량

## 2. 지금은 어떻게 분석하나요

| 질문 | 답변 |
| --- | --- |
| 주로 쓰는 분석·보고 도구는 무엇인가요? (엑셀, BI 도구, ERP 보고서, 외부 용역 등) | |
| 누가, 얼마나 자주 분석하거나 보고서를 만드나요? | |
| 정기적으로 만드는 보고서나 매일 확인하는 지표가 있다면 | |
| 지금 방식에서 가장 시간이 많이 들거나 아쉬운 점은 무엇인가요? | |

## 3. 데이터는 어떻게 저장·관리되나요

| 질문 | 답변 |
| --- | --- |
| 주요 업무 시스템과 데이터베이스는 무엇인가요? (예: 사내 서버의 ERP, 클라우드 그룹웨어) | |
| 분석용으로 데이터를 꺼낼 때는 어떻게 하나요? (파일 내보내기, API, DB 직접 조회, 담당 부서에 요청 등) | |
| 데이터를 관리하는 부서나 담당자가 따로 있나요? | |
| 보존 기간이나 백업 기준이 있다면 | |

## 4. 데이터 접근 보안 규정이 있나요

| 질문 | 답변 |
| --- | --- |
| 누가 어떤 데이터를 볼 수 있는지 정한 규정이 있나요? (부서별, 직급별, 담당 고객별 등) | |
| 외부 클라우드나 외부 AI 서비스에 데이터를 올리는 것이 허용되나요? (가능 / 가명 처리 후 가능 / 불가) | |
| 개인정보나 대외비 데이터는 어떻게 따로 관리하나요? | |
| 업무망과 인터넷망이 분리되어 있나요? | |
| 사내에서 운영 중이거나 도입을 검토 중인 AI 모델이 있나요? | |

## 5. 그 밖에 알려 주실 내용 (선택)

도입으로 기대하는 점, 꼭 확인하고 싶은 기능, 우려되는 점 등을 자유롭게 적어 주세요.
