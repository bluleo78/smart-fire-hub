# 거래처 신용 평가 보고서 — ㈜가온정밀

- 작성: 재무팀 이민수
- 평가 기준일: 최근 12개월 거래 실적

## 1. 거래 현황
- 업종: 자동차 부품 / 영업권역: 수도권 / 현재 등급: C
- 여신 한도: 3억 원
- 최근 12개월 매출은 크지 않으나 거래 빈도는 꾸준하다.

## 2. 결제 이력
- 만기 내 입금 비율이 70% 안팎으로 전체 거래처 평균보다 낮다.
- 현재 만기가 지난 미수 채권이 2건 있으며, 구매 담당자 교체 이후 회신이 늦어지고 있다.

## 3. 판단
- 등급은 C를 유지한다. 여신 한도 증액 요청은 받아들이지 않는다.
- 미수 채권이 60일을 넘으면 신규 출하를 보류하고, 선입금 조건으로 전환한다.

## 4. 후속 조치
1. 영업담당은 새 구매 담당자와 미팅을 잡아 결제 일정을 확인한다.
2. 재무팀은 매주 미수 현황을 영업회의에 공유한다.
