# 단가 협상 메모 — 하람시스템즈 배터리 팩

- 작성: 호남권 영업담당 서예린
- 상대: 하람시스템즈 구매팀(에너지 저장 설비)

## 요청 내용
하람시스템즈는 내년 배터리 팩 발주 물량을 올해보다 30% 늘리는 대신 단가 8% 인하를 요청했다. 경쟁사 견적서(단가 6% 낮음)를 근거로 제시했다.

## 내부 검토
- 현재 배터리 팩 매출총이익률은 약 17%. 8% 인하 시 이익률이 10% 아래로 떨어진다.
- 영업회의 결정(이익률 15% 하한)에 따라 인하 폭은 최대 3%까지만 가능하다.
- 대안: 단가 3% 인하 + 유지보수 서비스 연간 계약 묶음 제안. 유지보수 서비스는 이익률이 높아 전체 거래 수익성을 보전할 수 있다.

## 다음 단계
1. 11월 둘째 주까지 수정 견적 제출.
2. 결제 조건(현행 90일)은 바꾸지 않는다.
3. 경쟁사 견적서는 비밀 유지 대상이므로 외부 공유 금지.
