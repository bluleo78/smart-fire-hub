# 품질 이슈 보고서 — 커넥터·케이블 이물질 혼입

- 작성: 품질보증팀 / 배포: 영업본부, 생산본부
- 관련 거래처: 다솜오토텍(영남권, VIP), 버금 오토텍(호남권)
- 대상 제품: 커넥터·케이블 CN-220 계열, 생산 로트 L2609-14 ~ L2609-17

## 1. 현상
다솜오토텍 입고 검사에서 커넥터 포장 상자 안에 비닐 조각과 금속 분진이 발견되었다. 해당 거래처는 자사 고객사 출하를 보류했고, 같은 로트를 받은 버금오토텍에도 예방 점검을 요청했다. 영업담당 강민재가 1차 접수했다.

## 2. 원인
- 포장 라인 2호기의 커버가 정비 후 제대로 닫히지 않아 외부 이물질이 유입되었다.
- 출하 전 최종 검사가 표본 검사(로트당 50개)로만 이루어져 혼입을 놓쳤다.

## 3. 조치
1. 해당 로트 3,200개 전량 회수 및 재검사(완료율 85%).
2. 포장 라인 2호기 커버 잠금 장치 교체, 정비 후 점검표에 "커버 체결 확인" 항목 추가.
3. 4주 동안 CN-220 계열 출하 전 전수 검사 시행.

## 4. 영업 영향
- 다솜오토텍은 같은 유형의 불량이 세 번째라며, 개선이 없으면 다음 분기 물량을 다른 공급사로 옮기겠다고 통보했다.
- 회수·재검사 비용 약 1,800만 원, 다솜오토텍 대상 신용 메모(credit memo) 발행 검토 중.

## 5. 재발 방지
포장 공정 이물질 관리 기준을 개정하고, 거래처별 불량 이력을 월간 품질 회의 안건으로 올린다.
