# 제품 사양서 — 센서 모듈 SM-300 시리즈

## 개요
SM-300은 설비 상태 감시용 복합 센서 모듈로 온도·진동·전류를 함께 측정한다. 제어 보드 CB-500과 함께 쓰도록 설계되었다.

## 주요 사양
| 항목 | 값 |
|---|---|
| 측정 항목 | 온도(-40~125℃), 진동(3축, ±16g), 전류(0~50A) |
| 통신 | CAN 2.0B, RS-485 |
| 전원 | DC 12~24V, 소비전력 1.8W |
| 보호 등급 | IP67 |
| 보증 기간 | 납품 후 12개월 |

## 적용 거래처
미리내정밀(충청권)이 신규 사양(무선 통신 옵션) 평가를 진행 중이며, 해솔시스템즈(수도권)는 조선 기자재 감시용으로 쓰고 있다.

## 유지보수
펌웨어는 제어 보드를 통해 원격으로 업데이트한다. 업데이트 뒤 재부팅이 반복되면 이전 버전으로 되돌리고 기술지원팀에 로그를 보낸다.
